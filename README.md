# Vox

Vox is a voice companion for the Mac. You talk, she listens, answers out loud, and can hand whole tasks to coding
agents running in your terminal.

## Download

Get the newest `Vox-<version>.dmg` from [Releases](../../releases/latest), open it and drag Vox to Applications.
Each DMG is signed with a Developer ID, notarized by Apple, and published with its SHA-256 checksum (`.sha256`).

Needs macOS 14 or later on Apple silicon. The first launch asks for Microphone access; some features also ask for
Input Monitoring or Accessibility, and only when you turn them on.

## Updates

Vox updates herself from this page: she checks for a newer release, verifies its checksum, Apple signature and
notarization, and installs it when you choose Restart to Update or the next time she quits. Versions go 1.0, 1.1,
1.2 … 1.10 … one step per change.

## About this repository

This repository only publishes Vox's releases. Vox's source code is not public yet.
